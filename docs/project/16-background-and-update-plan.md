# 面板背景与更新说明计划

借鉴 CodexUsage 的开发版，适配 GlmUsage；经本地部署供用户验收后发布。

1. 页头提供纯色、经典毛玻璃、液态玻璃选择并保存；默认纯色。液态玻璃要求 macOS 26，旧系统回退经典毛玻璃；系统降低透明度时使用纯色。
2. 更新检查保存同一可安装 Release 的版本和说明。点击入口在面板内展开说明，取消或关闭不下载；确认时核对版本及说明未变化，然后沿用现有更新器与进度行。长说明可滚动；说明缺失提供明确提示。
3. 发布脚本采用仓库内的版本说明文件，空或缺失时停止；已有 Release 的说明不一致时停止，避免覆盖既有内容。
4. 构建并执行自检、峰谷和脚本回归，使用假数据预览与交互验证；明确真实升级与不同系统版本的验证范围。
