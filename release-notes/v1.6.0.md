## 悬停显示状态面板

- 悬停菜单栏图标约 0.2 秒自动打开面板；移入面板不收起，离开图标与面板约 0.3 秒后收起。
- 悬停打开后首次点击转为固定常开，移动鼠标不再自动收起；面板内点击同样固定，点击图标仍可正常开关面板。
- 图标与面板间缝隙在离开判定中宽容处理，擦边经过不会误收；面板内拖拽或弹出菜单期间不会收起。
- 页头「···」菜单新增「悬停显示状态面板」开关，默认开启，切换即时生效并保存在本机。

## OAuth 连接的额度周期历史持久化

- OAuth 回退连接（未保存 API Key）的额度周期历史此前仅存于当次运行，重启或更新后清零；现在按 ZCode 登录账号域隔离持久化，跨重启与更新保留。
- 身份无法证明（凭据不完整、解密失败、异常配置）时自动退回仅当次运行模式；登录态 token 轮换不改变历史归属；账号切换得到独立历史，与 API Key 的连接隔离、更换不合并规则一致。
- 用卡归因证明仍不落盘：重启载入的历史一律不标注主动重置，归因口径与 API Key 分区同规则。

保持额度刷新节奏、重置卡二次确认与既有 API Key 历史分区行为不变，无新增第三方依赖。
