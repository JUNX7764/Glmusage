## ZCode 4.0 凭据适配

- 新增适配 ZCode 4.0 通过 `zai_cn` 账号关联 BigModel 的新凭据结构（`oauth:linked_bigmodel`），自动读取套餐额度、Token/用量与重置卡，并保留原有 `enc:v2:os:` 钥匙串待授权引导；高优先级凭据异常时绝不静默降级。
- 为关联 BigModel OAuth 使用独立周期历史分区域（`oauth-linked`），避免与直连 OAuth 账号 ID 空间混用；切换凭据时同步清空旧账号邮箱展示，防止跨账号残留。

## 连接设置交互修复

- 为菜单栏应用补齐标准 Edit 主菜单，修复「连接设置」弹窗输入框无法使用 `⌘V`、`⌘C`、`⌘X`、`⌘A`、`⌘Z`、`⇧⌘Z` 等编辑快捷键的问题。
- 修复点击「验证并连接」或「解锁凭据」后菜单栏面板收起导致进度与失败原因不可见的体验盲区：同步交互返回后自动以常开态重新展开面板展示反馈，异步网络回调在用户已切往其他应用时不强行弹窗打断。
